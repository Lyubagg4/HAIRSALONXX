# Beauty Salon

Информационная система для управления салоном красоты.

## Возможности

- авторизация пользователей;
- разграничение ролей администратора и руководителя;
- управление клиентами;
- управление мастерами;
- управление услугами;
- создание записей обслуживания;
- просмотр аналитических отчётов;
- валидация вводимых данных;
- уведомления об ошибках и успешных действиях.

## Технологии

### Backend
- Java 17
- Kora
- PostgreSQL
- JDBC
- JWT

### Frontend
- React
- Vite
- Axios
- CSS
